## Blog keyword ownership and audit sheet

Keep `Current keyword focus (page content)` and `Target primary keyword` separate. Ground current focus in existing title/H1/content; mark unclear optimisation and local drafts explicitly. Current editorial focus is not a verified Google ranking query; only label rankings when supported by GSC. Read column headers before updates because inserted columns may shift ranges.

The keyword page map is the complete site URL register, not only a blog list. Maintain one row per URL for every public page, ads landing page, legacy/redirect URL and private/utility page; explicitly mark pages without an SEO target. Reconcile additions against the sitemap and application page routes. API endpoints and machine-readable files are not keyword landing pages. Preserve the distinction between live pages, local drafts, proposed changes and verified redirects.

When creating, materially revising, renaming or publishing a blog, maintain the existing `keyword page map` tab (gid 2306) in https://docs.google.com/spreadsheets/d/1Hc2wQKikWIO4wuRiHjXg3_-Twv0j7ZVvk5rsao4mIAI/edit . Read the live tab before choosing targets. Use one owner for each primary query and search intent; distinguish informational pillars, distinct spokes and commercial service pages. Extend an existing article when the intent is already covered.

Update the article's existing row (avoid duplicates) with its final URL, primary and supporting targets, intent boundary, evidence, internal links, current publication status and update date. Separate measured seed demand from unmeasured suggested variants; never assign a broad seed's volume to every spoke or treat city-targeted volumes as city-qualified phrases. Preserve unrelated sheet data and verify edits. Do not mark a local draft published. If sheet access fails, report the pending sync explicitly.
