# Payroll Studio — V4 presentation

Adapted from CiteAgentic V4: Bricolage Grotesque display typography, Inter UI text,
white and cool-gray surfaces, dark neutral text, burnt-orange primary actions.

- Shared tokens: `app/globals.css`; editable brand settings: `content/settings.yaml`.
- Primary action: #b34a22, hover #c25a30. Secondary text: #626b78.
- Cards: white, fine #dfe3e8 borders, 12px corners, subtle neutral shadows.
- Layout: max-w-7xl containers and responsive section spacing.
- Hero: two-column desktop layout; single-column mobile with full-width actions.
- Visible keyboard focus; reduced-motion CSS; no hidden entrance-animation content.

MDX copy, metadata, section order, URLs and integrations are retained. Legacy
section colour fields are mapped to neutral presentation in shared components.
Shared CTA links are styled as links without nested interactive buttons.

Validation: production build and targeted lint pass; homepage text, destinations
and metadata match the previous version. Mobile navigation, FAQ toggles and
the contact route and HubSpot form embed were checked. Live enquiries were not submitted.
